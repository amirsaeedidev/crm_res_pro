# راه‌اندازی مرکز پیامک ملی پیامک

## پیش‌نیازها

- نسخه CRM با مسیر `/sms`.
- پنل فعال ملی پیامک، نام کاربری، API Key/رمز وب‌سرویس و شماره فرستنده مجاز برای پیام عادی.
- برای حالت پترن: Body ID فعال و ترتیب پارامترها مطابق همان الگو.

## راه‌اندازی

1. با کاربر مدیر فعال وارد پنل CRM شوید و از منو، «مرکز پیامک» را باز کنید.
2. نام کاربری را وارد کنید و API Key را وارد/ذخیره کنید. کلید از طریق RPC مدیریتی به Supabase Vault ذخیره می‌شود؛ اگر کلید قبلی وجود دارد، برای نگه‌داشتن آن فیلد API Key را خالی بگذارید.
3. برای پیام عادی، شماره فرستنده را تنظیم کنید. برای پترن، Body ID پیش‌فرض یا Body ID هر قالب را وارد کنید.
4. تعداد تلاش را (۱ تا ۱۰، پیش‌فرض ۵) و فاصله تلاش مجدد را تنظیم کنید.
5. گزینه SMS را فعال کنید. ابتدا با شماره‌ای که اجازه دارید از آن استفاده کنید یک پیام آزمایشی را صف‌بندی و بعد وضعیت تلاش‌ها را در لاگ بررسی کنید.
6. برای پیام بازاریابی فقط مشتریانی که رضایت پیامک تبلیغاتی آن‌ها صریحاً ثبت شده قابل انتخاب‌اند. رضایت مشتری به‌صورت پیش‌فرض خاموش است.
7. از بخش پرسنل، نام، شماره، نقش و نوع سفارش‌های مجاز هر نفر را تنظیم کنید. پیام سفارش شامل خلاصه اقلام، نوع سفارش، مبلغ، شماره میز و یادداشت است و فقط برای پرسنلی صف می‌شود که نوع سفارش را دریافت می‌کنند (یا فردی که مشخصاً به سفارش تخصیص داده شده است).

## رویدادهای خودکار

- ثبت تیکت جدید: پیام به مدیر و/یا مشتری، بر اساس گزینه‌های تنظیمات.
- پاسخ مدیر به تیکت: اعلان به مشتری.
- آماده‌شدن سفارش (وضعیت `ready`): اعلان به مشتری.
- سفارش جدید: اعلان به پرسنل فعال که نوع سفارش مربوط به آن‌هاست؛ در صورت تخصیص سفارش به یک پرسنل، همان پرسنل هدف می‌شود.

## وضعیت و لاگ

جدول `sms_outbox` صف و وضعیت نهایی را نگه می‌دارد و `sms_attempt_logs` برای هر تلاش، کد پاسخ، نتیجه، شناسه پیامک و خطا را ثبت می‌کند. `sms_delivery_stats_view` داده نمودار را فراهم می‌کند.

Job کران Supabase با نام `crm-sms-dispatch-every-minute` هر دقیقه `sms-dispatch` را اجرا می‌کند. ارسال واقعی به واردشدن اعتبارنامه‌های واقعی و روشن‌کردن SMS بستگی دارد. هیچ کلید API یا کلید `service_role` را در سورس Flutter قرار ندهید.

## مستندات API ملی پیامک

پیاده‌سازی بر پایه API REST این دو endpoint است:

- پیام عادی: `https://rest.payamak-panel.com/api/SendSMS/SendSMS`
- ارسال بر اساس الگو: `https://rest.payamak-panel.com/api/SendSMS/BaseServiceNumber`

فیلدها و کد پاسخ ممکن است طبق نوع سرویس و حساب پنل متفاوت باشند؛ الگوی واقعی حساب خود را با مستندات/نمونه رسمی فروشنده تطبیق دهید. من بدون اعتبارنامهٔ واقعی، ارسال پولی انجام نداده‌ام.
